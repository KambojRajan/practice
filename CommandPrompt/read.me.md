Requirements
- Functional
  - We must support cd, ls, pwd, mkdir, cat, echo.
  - We as well must suppot  pipe(|) and rediction(>)
  - each command should be correctly parsed
  - we should follow repl loop
- Non-Functional
  - We must be able to extend a new command without changing the parser
  - parsing should consider of tokenization ("hello world" is one not two argument)
  - Errors should be clean and clear
